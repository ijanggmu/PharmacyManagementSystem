# Project guidance

Engineering conventions and architecture rules for the pharmacy web app live in **`rule.md`** in this folder (`clients/pharmacywebapp/`). Read it first. It covers the Next.js BFF over the .NET API: the `/api/dotnet` proxy, httpOnly sessions and the Redis token store, CSRF, `dotnet-permissions.ts`, feature folders, i18n (English/Nepali), BS date pickers, the offline POS queue, and Vitest/Playwright tests.

Repo-wide conventions (backend, modules, golden rules) are in `/AGENTS.md`. Architecture decisions are in `/docs/adr/`.
